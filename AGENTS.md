iff editing `.typ` files, write math equations using this reference from Typst: https://typst.app/docs/reference/ and not in md LaTeX.
To run a python program use `uv run <script>.py`
To compile/render a `.typ` file to `.pdf` use `typst compile path/to/file.typ --root .`
When writing code, never reinvent the wheel; rather, always try to reuse APIs of established librares and frameworks rather than attempting to do a helper / utility function.
